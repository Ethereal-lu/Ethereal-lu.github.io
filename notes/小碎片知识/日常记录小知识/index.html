2 虚拟机网络问题#

2.1 虚拟机网络无法连接#

  • 问题描述：银河麒麟虚拟机网络无法连接，提示“未插入对应的网卡网线”
  • 解决方法：重启网络服务，步骤如下
    1. systemctl stop NetworkManager && systemctl disable NetworkManager
    2. systemctl restart NetworkManager

2.2 虚拟机挂起后，影响 docker 网络#

  • 问题描述：虚拟机挂起再继续运行后，外部网络无法访问 docker
  • 解决方法：重启 docker 网络服务 systemctl restart NetworkManager docker
